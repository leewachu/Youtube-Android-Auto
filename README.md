# ParkedTube V1

An experimental YouTube embedded-player Android app for **phone use while safely parked**.

Android Auto support for video is currently restricted: this project does **not** guarantee that the app appears on a 2019 Volkswagen Tiguan Allspace head unit. Android 17 on the phone does not override head-unit eligibility.

APK builds are created via GitHub Actions. See Actions > Build ParkedTube APK > run / artifacts.

Do not use or watch video while driving. This experimental phone app has a manual parked confirmation only, and cannot independently verify vehicle motion.
